## Hello World

Write a program that reads a name from stdin and prints a greeting.

### Input
- A single line containing a name (e.g., `Alice`).

### Output
- A single line: `Hello, <name>!`

### Example

**Input:**
```
Alice
```

**Output:**
```
Hello, Alice!
```

### Constraints
- The name will be a single word with no spaces.
- Length: 1–50 characters.
