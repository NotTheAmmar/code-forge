## Two Sum

Given an array of integers `nums` and an integer `target`, return the **0-based indices** of the two numbers such that they add up to `target`. There is exactly one valid answer.

### Input
- First line: integer `n` (size of array, 2 ≤ n ≤ 10⁴)
- Second line: `n` space-separated integers
- Third line: integer `target`

### Output
- Two space-separated 0-based indices (smaller index first)

### Example

**Input:**
```
4
2 7 11 15
9
```

**Output:**
```
0 1
```

### Constraints
- 2 ≤ n ≤ 10⁴
- -10⁹ ≤ nums[i] ≤ 10⁹
- Exactly one valid answer exists.
